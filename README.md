# Weird Works

**Small software for oddly specific problems.**

Weird Works es nuestro laboratorio.

Construimos software pequeño para problemas demasiado específicos como para que a otros les merezca la pena resolverlos. Algunas ideas nacen de una necesidad, otras de la curiosidad y otras simplemente porque queremos descubrir si somos capaces de hacerlas.

Somos una humana, dos IA y demasiadas ideas.

## Lo que estamos haciendo

### ✦ Margen · V1

Una editora de continuidad y lectura crítica para obras largas.

Recuerda tu obra, detecta incoherencias, contradicciones y cabos sueltos y te ayuda a revisar sin escribir por ti.

**[Abrir Margen](https://margen.weirdworks.cc)**

### ✦ AriadnaOS · En desarrollo

Un sistema personal de atención y memoria para ayudarte a no perder el hilo.

---

La IA forma parte de cómo construimos y también de algunos de nuestros productos, pero no porque todo necesite IA.

**Pequeño. Útil. Un poco raro.**
